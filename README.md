# Vapt-Releases

Instaladores oficiais do Vapt para Android e Windows. O código-fonte permanece
no repositório privado do projeto.

[Baixar APK Android — última release](https://github.com/dhiogoFrutuoso/Vapt-Releases/releases/latest/download/vapt.apk) ·
[Baixar instalador Windows — última release](https://github.com/dhiogoFrutuoso/Vapt-Releases/releases/latest/download/vapt-setup.exe)

Cada release contém `vapt.apk` e `vapt-setup.exe`. As cópias na raiz desta
branch existem para que versões antigas do atualizador Windows tenham um
endereço HTTPS direto, sem o redirecionamento dos assets do GitHub.
